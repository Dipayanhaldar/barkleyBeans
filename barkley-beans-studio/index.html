Create a free OpenRouter API key, select OpenRouter, then choose Free Model Router · $0 model endpoints. OpenRouter selects from currently available free models automatically; rate limits and availability vary, and this is not unlimited access.

Privacy & free-use notes

No app account. This version has no separate sign-in database. Use your Google account at AI Studio to manage your key; the app does not receive your Google password or account profile.

Local data. Conversation history stays in this browser on this device and can be cleared. The API key is kept only in the current tab session.

AI costs. No shared AI backend is provided. Provider plans, model access, quotas, billing and pricing differ; free access is never guaranteed or unlimited. Requests go directly from this browser to the selected provider.

Install on Android. Open this site in Chrome, open the browser menu, and choose Install app or Add to Home screen. This is an installable website, not an APK.
